# Analysis Log

Append-only record of substantial work that changed no code: audits (UI/UX, security, performance),
code reviews, investigations, status checks, and plans. Code changes go in `evolution_log.md`.
Rules: `.ai_ledger/agent_directives.md`. Older months: `.ai_ledger/archive/analysis/`.

**How to read an entry:** **Findings** is what the AI discovered, and **Recommended next steps** is what
to do about it. **Request vs Result** shows whether it covered everything you asked.
